# SD Shopping Site Workspace Guidelines

## Overview
This workspace (`sd-shopping-site`) is a Node.js Express e-commerce application featuring Gmail OTP authentication and custom 3D animated UI.

## Environment & Run Commands
- **Start server**: `npm start` (runs `server.js`)
- **Development**: `npm run dev` (runs `nodemon server.js`)
- **Environment variables**: Configured in `.env`

## Workspace Structure
- `server.js`: Main Express entry point
- `routes/`: API endpoint handlers
- `models/`: Database models / Mongoose schemas
- `db/`: Database configuration
- `index.html`: Main frontend UI
- `script.js`: Interactive frontend logic
- `style.css`: Styling and theme definitions
